# Assets

| Path | What |
|---|---|
| `source-portfolio.pdf` | your supplied portfolio PDF — the source of all artwork |
| `portrait/` | **drop a high-resolution portrait here** (see the README inside) |
| `derived/` | artwork extracted from the PDF — regenerated automatically |

`derived/` is regenerated in about two seconds from the PDF by
`assets.ensure_extracted()`; it is not committed to git.
