# Drop your portrait here

Put a high-resolution portrait in this folder — `.jpg`, `.jpeg`, `.png`,
`.webp`, `.tif` or `.tiff`. **The largest file in this folder wins** and is used
automatically on the next render. No code change, no re-crop.

Aim for at least **1200 × 1500 px**, portrait orientation, with some space above
the head. Face position is detected automatically and held in the upper third.

Until you add one, the film uses `assets/derived/portrait_embedded.jpg`
(612 × 720, recovered from your banner SVG) as a stand-in.
